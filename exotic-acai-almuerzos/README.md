# Exotic Açaí · Suscripción de almuerzos (demo)

Demo funcional: landing → flujo de suscripción → panel interno con roles.

```bash
python3 -m http.server 8765      # desde esta carpeta
```
- Landing: `http://localhost:8765/`
- Flujo de suscripción: `http://localhost:8765/suscribirse.html`
- Panel interno: `http://localhost:8765/admin/` (elige un usuario; modo demo)

Prueba el embudo con una fuente: `/?utm_source=instagram&utm_campaign=reel-almuerzo-oficina`.
