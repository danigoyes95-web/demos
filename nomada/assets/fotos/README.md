# Fotos del demo

Las fotos actuales son **de prueba**, recortadas de capturas del Instagram @nomada.amb (baja resolución).
Reemplázalas por las originales manteniendo el nombre de archivo, o cambia la ruta desde el panel (Menú → foto).

- `platos/` tiradito-corvina, lomo-remolacha, ensalada-cuscus, coliflor-horno, gyozas, lomo-yema
- `cocteles/` coctel-rojo, coctel-espuma
- `cervezas/` (vacía: pendiente de fotos de cervezas)
- `eventos/` (pendiente: afiche de cada evento; mientras tanto se usan fotos de `ambiente/`)
- `equipo/` chef-retrato, chef-emplatando, sommelier
- `ambiente/` mesa-servida, llama-paja, deshidratador, cuchillos, algas

Medidas recomendadas: platos y bebidas 1200×1500 (4:5), eventos 1600×900, equipo 1000×1250.
